## [0.1.0] - 2026-09-22

- Added model/runtime cache management, offline mode, and checksum validation.
- Added `/health`, `/v1/models`, and `/v1/systemone` HTTP endpoints.
- Added cross-platform CI and managed llama.cpp runtime provisioning.
